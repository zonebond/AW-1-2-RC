# AW 1+2 RC

一个从零实现的格子回合制战棋，玩法取自《Advance Wars》系列，画面走塑料玩具兵人的 3D 风格。

**这不是移植，也不是复刻原版资产。** 单位模型、地形、UI、配色全部是代码程序化生成的，没有使用任何任天堂 / WayForward 的素材。玩法规则（地形消耗、兵种数值、伤害公式）参照系列的公开机制实现。

## 在 macOS 上运行

需要 [Node.js](https://nodejs.org/) 18 以上。

```bash
npm install
npm run dev
```

然后打开终端里输出的地址（默认 http://127.0.0.1:5173/）。

打包成静态站点：

```bash
npm run build     # 输出到 dist/，同时跑一遍类型检查
npm run preview   # 本地预览打包结果
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键点自己的单位 | 选中，显示蓝色移动范围和红色可攻击范围 |
| 左键点蓝色格子 | 移动过去，弹出行动菜单 |
| 右键 / `Esc` | 取消。移动后取消会让单位走回原位 |
| 左键点自己的空工厂 | 打开生产菜单 |
| **左键拖动** | 平移镜头（触控板没有中键，所以左键拖动是主要方式） |
| `W` `A` `S` `D` / 方向键 | 平移镜头 |
| **空格** | 镜头重新对准自己的部队 |
| 滚轮 / 触控板双指 | 缩放（开局默认拉近，滚出去可看全图） |
| 中键拖动 | 平移 |
| `E` | 结束回合 |
| 点顶栏「迷雾」 | 开关战争迷雾（会重开一局） |
| `M` | 静音 / 取消静音 |
| `N` | 开关背景音乐 |

镜头的平移范围永远被限制在棋盘内：缩放时会重新夹取，所以**不存在把视角推丢、回不来的情况**。真的迷路了，按空格。

选中「攻击」后，鼠标悬停在敌方单位上会显示伤害预测：双方 HP 的变化、对方是否会反击、能否一击击毁。预测按运气值 0 计算，也就是**实际伤害只会等于或高于显示值**。

## 规则要点

- **HP 与伤害**：单位内部 HP 为 0–100，显示为 1–10。伤害公式为
  `(基础伤害 + 运气0~9) × (攻方HP/10) × (100 − 地形星级 × 守方HP) / 100`。
  受伤的单位打得更轻，同时躲在掩体里也更耐打。
- **反击**：只有相邻的直射单位会反击。火炮和火箭炮不反击，也没人能反击它们——这是带间接单位的全部意义。
- **间接单位**：射程大于 1 的单位**移动后不能攻击**，必须提前架好位置。
- **占领**：步兵和机步可占领城市 / 工厂 / 司令部。每回合按自身显示 HP 扣减占领点数，满 20 点易主。占领途中离开或阵亡，进度清零。
- **补给**：停在己方建筑上的单位每回合回复 2 HP（按造价比例扣钱）并补满弹药燃料。
- **胜负**：占领敌方司令部，或全歼敌方单位。

交战时会切入**战斗过场**：镜头压低推到双方之间，加上下黑边和双方的名字与血条，打完再切回战术视角。嫌慢可以用 `?cutscene=0` 关掉。

## 地图

地图写成两字符一格的文本网格，见 `src/core/map.ts` 的说明。两张内置地图都是 180° 旋转对称的，双方开局条件完全相同。

用 `?map=crossroads` 切换地图。加地图只要在 `src/core/maps.ts` 里加一段字符串和起始单位。

## 代码结构

```
src/core/     规则内核。不引用 three.js，可以独立运行
src/ai/       AI。单回合贪心 + 敌方威胁图
src/render/   three.js 渲染层。程序化几何体、材质、镜头、动画
src/ui/       DOM 界面与交互状态机
src/audio/    Web Audio 程序化音效与音乐。没有音频文件
tools/        开发工具（见下）
```

`src/core` 与渲染完全解耦，这也是为什么规则可以用无头脚本整局验证。

## 开发工具

```bash
npm test                                    # 规则引擎确定性测试（118 项断言，秒级）
npm run simulate -- twin-bridges 60 12345   # 无头 AI 对 AI 整局对战
npm run simulate -- twin-bridges 40 1 fog   # 同上，但开着战争迷雾
npm run playtest -- /tmp/shots              # 真实浏览器操作全流程 + 断言 + 截图
npm run cutscene -- /tmp/shots              # 战斗过场：逐帧截图 + 断言
npm run audio                               # 离线渲染每个音效并测量波形 + 断言
node tools/shot.mjs "URL=>输出路径.png"       # 单张截图
```

测试分两层，各管各的：

- `tools/rules-test.ts` 用固定棋盘和固定运气值断言精确数值——伤害公式、地形消耗、占领节奏、反击规则、胜负条件。规则对不对由它说了算。
- `tools/playtest.mjs` 开真浏览器点界面——选中、移动、取消、占领、生产、攻击预测、AI 回合、重开局。它不断言规则细节，因为一局里能不能占下城市取决于对手怎么打，那不是界面测试该管的事。
- 迷雾的规则（视野半径、森林隐蔽、山地加成、伏击截断）全部在 `rules-test.ts` 里断言；浏览器测试只负责确认**画面上真的没画出来**——规则层和渲染层各测各的，才不会出现「规则算对了但敌人还杵在屏幕上」。
- `tools/audio-test.mjs` 用 `OfflineAudioContext` 把每个音效离线渲染成波形，断言它有声音、不削波、实际余响长度与声明时长对得上。它当然听不出好不好听，但「某个音效改崩了、没声了、爆音了」它一定拦得住。

调试用 URL 参数：

| 参数 | 说明 |
| --- | --- |
| `?view=units` | 九种兵种双方涂装的近景陈列 |
| `?view=board` | 静态战场，用于看地形和光照 |
| `?view=fx` | 战斗特效实验室，可手动步进时间轴 |
| `?shadow=0\|512\|1024\|2048` | 阴影贴图分辨率，0 为关闭 |
| `?speed=N` | 动画倍速（≥4 时自动关闭战斗过场） |
| `?cutscene=0` | 关闭战斗过场，攻击直接在战术视角结算 |
| `?manual=1` | 把时间轴交给脚本手动步进，用于精确截取动画帧 |
| `?fog=1` | 开着战争迷雾开局 |
| `?aa=0` | 关闭抗锯齿 |

## 战争迷雾

顶栏的「迷雾」按钮可以开关，也可以用 `?fog=1` 直接开着进游戏。**地形永远是已知的**——你一直看得见山在哪、工厂在哪、谁占着哪块地；迷雾拿走的只是**对单位的感知**。

规则：

- 每个单位按自身视野照亮一个**菱形**范围（曼哈顿距离，不是方框）。
- **自己的建筑**也会照亮周围 2 格，所以后方不会全黑。
- **森林里的单位藏得住**：哪怕那格是亮的，也只有**紧挨着**它的单位才能发现它。
- **步兵和机步站上山地视野 +3**。这是把步兵送上山头的真正理由，而不只是为了那 4 颗防御星。
- 看不见就打不到，也不显示单位信息面板。
- **伏击**：迷雾下你可以把路线规划穿过一格你以为是空的地方。真撞上了，部队就在**前一格停下**，这一回合也就到此为止。

AI 用的是同一套 `visibleUnits()`，它看到的和你一样多——它不会作弊，也一样会踩进伏击。视野里一个敌人都没有时，它会朝敌方司令部推进，而不是原地发呆。

## 音效与音乐

全部是**程序化合成**的：`src/audio/` 里没有一个音频文件，所有声音都由振荡器和滤波噪声在运行时算出来。这样既没有素材版权问题，也不用为几十个音效背上几 MB 的下载。

- `synth.ts` 两个原语：`tone()` 带包络与滑音的振荡器，`noise()` 过滤波器的噪声。
- `sounds.ts` 19 个音效——光标、选中、取消、菜单、三种移动声（脚步 / 履带 / 轮胎，按兵种自动选）、机枪、炮击、火箭、命中、击毁、占领进度、占领完成、生产、双方回合号角（用不同调性，不看画面也知道轮到谁）、胜利、失败。
- `music.ts` 一段**原创**的小调进行曲循环（Am–F–C–G，112 BPM，八小节）。原版配乐没法复刻，这是我自己写的。
- `audio.ts` 一个 AudioContext、音效与音乐两条总线。浏览器不允许在用户操作前出声，所以上下文是在第一次点击或按键时才创建的。静音和音乐开关记在 `localStorage` 里。

音乐是提前排程、每半个循环补一次队的，所以按 `N` 关音乐能立刻生效，而不用等当前循环放完。

开火声不是按兵种写死的，而是**跟着实际使用的武器走**：坦克打步兵是并列机枪的连响，打坦克才是主炮的一声闷响；机步对装甲用火箭筒、对步兵用机枪。这跟伤害计算用的是同一个 `chooseWeapon()`，所以听到的声音和结算的武器永远是同一件。
